Module Specification: slugifier/slug.py

Implement the function to_slug(text, max_len=None) with the following rules:

  1. Convert all characters to lowercase.
  2. Replace any sequence of non-alphanumeric characters (spaces, punctuation) with a single hyphen -.
  3. Strip leading and trailing hyphens.
  4. If max_len is specified and the slug exceeds max_len, truncate to max_len characters, removing any trailing hyphen after truncation.
  5. If the resulting string is empty, return an empty string.
